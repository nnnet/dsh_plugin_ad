# Changelog

## 0.3.0

- Added campaign metadata and placement support.
- Added privacy-conscious targeting by locale, pathname and explicit host-provided tags.
- Added fallback source selection when the preferred source fails or has no eligible creatives.
- Added source priority/weight controls.
- Added impression, click and conversion tracking through a configurable source action.
- Added in-memory frequency capping by campaign/creative.
- Added anonymous per-browser-session ID for attribution and AI sessions; no account/profile data is generated by the plugin.
- Added campaign/creative/variant identifiers to normalized ad items.
- Added product/session context to AI chat requests.
- Added `/api/ad-pet/track` endpoint.
- Kept all source credentials host-side and configurable through environment variables or direct values.
- Updated marketplace example with fallback network, targeting, A/B variant fields and tracking.
